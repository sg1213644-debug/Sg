# DemoLockScreen — AndroidIDE build

This version is adjusted for an AndroidIDE environment using Gradle 6.1.1 / Java 8.

Build from AndroidIDE's Gradle menu with:
:app:assembleDebug

The resulting debug APK should be under:
app/build/outputs/apk/debug/app-debug.apk

This is a harmless demo lock-screen app. It does not collect or transmit PINs.
